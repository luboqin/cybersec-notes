# 第 2 课：`admin'\'' --` —— 真 SQL 注入

- **日期**：2026-10-07
- **靶场**：`/tmp/bad.py` 的第二版（sqlite3，**真查密码**）
- **一句话总结**：单引号提前闭合字符串，`--` 把后面的密码条件注释掉。

## 我做了什么

用户名框填：

```
admin'\'' --
```

密码随便填。

## 结果

直接进。服务器打印的实际 SQL：

```sql
SELECT * FROM users WHERE user='\''admin'\''
```

后面那半句 `AND pass='\''...'\''` 被 `--` 注释掉了。

## 学到的东西

- 服务器把你的输入**拼进句子**里，而不是当成"数据"
- `'\''` 是跳出字符串，`--` 是注释掉剩下的
- 正确写法：`SELECT * FROM users WHERE user=? AND pass=?` + `db.execute(sql, (user, pwd))`
  —— **命令与输入分开交**
