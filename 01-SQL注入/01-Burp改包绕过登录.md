# 第 1 课：Burp 改包绕过假登录

- **日期**：2026-10-07
- **靶场**：Kali 里 `/tmp/bad.py`，`http://127.0.0.1:8000`
- **一句话总结**：网页上填的东西是**明文发出去的**，谁站在半路谁就能改。

## 我想干什么

登录进 admin 的号，但我不知道密码。

## 我做了什么

1. 浏览器挂上 Burp 代理（127.0.0.1:8080）
2. **先让页面正常加载完**，再开 Intercept
3. 点登录，Burp 拦下那个 POST
4. 把 `user=zhangsan` 改成 `user=admin`
5. Forward 放行

## 结果

页面显示：**进来了！你是管理员**

## 学到的东西

- 网页表单提交就是一段**明文**，Burp 站在中间就能随便改
- Burp 就是那个"中间人"
- ⚠️ **顺序很重要**：先开 Intercept 再开浏览器，会把页面本身的 GET 也拦住，浏览器一直转圈

## 卡在哪

一开始卡在"浏览器转圈打不开页面" —— 是拦截开着导致的。
