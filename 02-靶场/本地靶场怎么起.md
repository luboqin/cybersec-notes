## 骨架（Python 标准库，不用装任何东西）

```python
# /tmp/bad.py   —— 用 python3 bad.py 起，浏览器开 http://127.0.0.1:8000
from http.server import BaseHTTPRequestHandler, HTTPServer
from urllib.parse import urlparse, parse_qs
import sqlite3

DB = sqlite3.connect(':memory:', check_same_thread=False)
DB.execute("CREATE TABLE users (user TEXT, pass TEXT)")
DB.execute("INSERT INTO users VALUES ('\''admin'\'', '\''Sup3rS3cret!!'\'')")

PAGE = """<form method="get" action="/">
  <input name="q"> <button>搜</button></form><pre>%s</pre>"""

class H(BaseHTTPRequestHandler):
    def do_GET(self):
        q = parse_qs(urlparse(self.path).query).get("q", [""])[0]
        sql = "SELECT * FROM users WHERE user = '\''%s'\''" % q
        print("服务器执行的 SQL >>>", sql, flush=True)   # 最值钱的一行
        try:
            rows = DB.execute(sql).fetchall()
            out = str(rows)
        except Exception as e:
            out = "出错了：" + str(e)
        self.send_response(200)
        self.send_header("Content-Type", "text/html; charset=utf-8")
        self.end_headers()
        self.wfile.write((PAGE % out).encode("utf-8"))

HTTPServer(("127.0.0.1", 8000), H).serve_forever()
```

## 三个必须记住的坑

1. **Kali 一关机，`/tmp` 就清空** —— 每次上课先确认脚本还在
2. **服务端一定要打印实际执行的 SQL** —— 这是全场最值钱的证据
3. **`\''--\'` 后面要有空格**，不然 SQL 认不出是注释
